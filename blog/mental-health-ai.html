1. The Cognitive Burnout Cascade & Observability

According to the World Health Organization (ICD-11 QD85), occupational burnout is an unmanaged chronic workplace stress syndrome characterized by three dimensions:

  1. Energy depletion and chronic exhaustion.
  2. Increased mental distance, negativism, or cynicism related to one's occupational duties.
  3. Reduced professional efficacy and heightened cognitive fatigue.

Traditional psychological evaluations rely on retroactive questionnaires like the Maslach Burnout Inventory (MBI) or PHQ-9. These suffer from severe retrospective reporting bias: by the time an engineer scores high on emotional exhaustion, they have already entered acute clinical distress.

Our mission was to build a passive, non-intrusive fitness tracker for cognitive health: analyzing everyday writing patterns (self-journaling, daily standup notes, message drafts) entirely on-device to flag statistically significant behavioral deviations 2 to 3 weeks before acute burnout strikes.

2. High-Level On-Device Pipeline Architecture

To maintain strict HIPAA and GDPR compliance, raw personal text must never leave the user's local hardware. All linguistic parsing, vectorization, and statistical drift calculations execute within a sandboxed local environment:

01
Local Text Ingestion & Tokenization

User logs daily reflection or work notes. Text is immediately preprocessed using Byte-Pair Encoding (BPE) with sensitive entity stripping (PII scrubbing via local regex).

02
Dual-Engine Sentiment & Valence Analysis

Combines fast rule-based VADER lexicon scoring (compound, positive, negative, valence intensity) with a fine-tuned INT8 RoBERTa emotional nuance model.

03
Time-Series Moving Window Z-Score Drift

Daily scores are ingested into an Exponentially Weighted Moving Average (EWMA) tracker that accounts for baseline variance, holidays, and weekend cycles.

04
Hard-Coded Clinical Triage & Interventions

If sentiment crosses a negative threshold for 5 consecutive days or triggers acute crisis markers, localized psychological resources are rendered immediately.

3. Mathematical Formulation: EWMA Affective Drift

Human mood naturally fluctuates throughout the week (e.g., Sunday night anticipation vs. Friday relief). A single negative entry should never trigger a false-positive burnout alarm. We model a user's emotional baseline as a decaying stochastic process:

Let $V_t \in [-1.0, +1.0]$ denote the composite sentiment score extracted on day $t$. The Exponentially Weighted Moving Average (EWMA) $\bar{S}_t$ and moving variance $\sigma_t^2$ are updated recursively:

EWMA Formulation
$$\bar{S}_t = \lambda \bar{S}_{t-1} + (1 - \lambda) V_t$$

$$\sigma_t^2 = \lambda \sigma_{t-1}^2 + (1 - \lambda) (V_t - \bar{S}_t)^2$$

$$Z_{\text{burnout}}(t) = \frac{\bar{S}_t - \mu_{\text{historical}}}{\sqrt{\sigma_t^2 + \epsilon_0}}$$

Where:

  • $\lambda \in [0.85, 0.95]$ is the memory decay factor, setting an effective observation horizon of roughly 14 to 20 days.
  • $\mu_{\text{historical}}$ represents the user's long-term individual emotional baseline established during an initial 14-day calibration phase.
  • An alarm is generated if and only if $Z_{\text{burnout}}(t) \le -2.0$ for 3 or more consecutive timestamps ($p < 0.022$).

4. Privacy Engineering: Local Differential Privacy

If high-dimensional embeddings were synced to a central analytics dashboard, an adversarial reconstruction attack could recover verbatim personal diary sentences. To protect users, we perturb aggregated behavioral statistics using the Laplace mechanism:

Differential Privacy Guarantee
$$\mathcal{M}(x) = f(x) + \text{Lap}\left( \frac{\Delta f}{\epsilon} \right)$$
$$P\left( \text{Lap}(b) = z \right) = \frac{1}{2b} \exp\left( -\frac{|z|}{b} \right), \quad b = \frac{\Delta f}{\epsilon}$$

With an $L_1$ sensitivity $\Delta f = 2.0$ (bounded valence swing) and a privacy loss budget $\epsilon = 1.15$, our mathematical guarantee ensures that an attacker cannot determine whether a specific distressing entry was logged with confidence greater than $e^{1.15} \approx 3.15$.

5. Production Implementation: Model & Guardrails

burnout_detector.py — Complete Emotion Analysis & Tripwire Engine
import math
import numpy as np
from typing import Dict, Any, Optional

class BurnoutAnomalyEngine:
    def __init__(self, lambda_decay: float = 0.90, z_threshold: float = -2.0):
        self.lambda_decay = lambda_decay
        self.z_threshold = z_threshold
        self.historical_mean = 0.0
        self.ewma_mean = 0.0
        self.ewma_var = 0.04  # Initial prior variance
        self.days_initialized = 0
        self.negative_streak = 0

        # Hard-coded crisis lexicons for immediate deterministic triage
        self.crisis_tripwires = [
            "suicide", "end it all", "kill myself", 
            "no reason to live", "self harm", "overdose"
        ]

    def check_crisis_tripwire(self, raw_text: str) -> bool:
        """Deterministic safety check bypassing probabilistic ML models."""
        text_lower = raw_text.lower()
        return any(term in text_lower for term in self.crisis_tripwires)

    def update_affect_timeseries(self, valence_score: float) -> Dict[str, Any]:
        """
        Updates the recursive EWMA state with today's compound score.
        valence_score: float in range [-1.0, 1.0]
        """
        self.days_initialized += 1

        if self.days_initialized == 1:
            self.ewma_mean = valence_score
            self.historical_mean = valence_score
            return {"status": "CALIBRATING", "z_score": 0.0, "risk_level": "LOW"}

        # Recursive EWMA Mean and Variance
        delta = valence_score - self.ewma_mean
        self.ewma_mean = self.lambda_decay * self.ewma_mean + (1.0 - self.lambda_decay) * valence_score
        self.ewma_var = (
            self.lambda_decay * self.ewma_var + 
            (1.0 - self.lambda_decay) * (delta ** 2)
        )

        std_dev = math.sqrt(max(self.ewma_var, 1e-4))
        z_score = (self.ewma_mean - self.historical_mean) / std_dev

        # Slowly adapt historical long-term baseline (98% persistence)
        self.historical_mean = 0.98 * self.historical_mean + 0.02 * valence_score

        # Risk Classification Logic
        if z_score <= self.z_threshold:
            self.negative_streak += 1
        else:
            self.negative_streak = max(0, self.negative_streak - 1)

        risk = "NORMAL"
        if self.negative_streak >= 3:
            risk = "CRITICAL_BURNOUT_WARNING"
        elif self.negative_streak >= 1:
            risk = "ELEVATED_STRESS"

        return {
            "status": "ACTIVE",
            "ewma_mean": round(self.ewma_mean, 4),
            "z_score": round(z_score, 3),
            "streak": self.negative_streak,
            "risk_level": risk
        }

7. Clinical Triage Guardrails & Ethical Constraints

AI in mental health carries severe ethical stakes. A misdiagnosis or an insensitive algorithmic hallucination can have catastrophic consequences:

Non-Diagnostic Clarification: The software explicitly positions itself as an administrative cognitive health telemetry monitor, not a medical diagnostic tool. It never outputs clinical diagnostic codes (e.g., DSM-5 Major Depressive Disorder).
Deterministic Hard-Tripwire Crisis Interception: Whenever acute crisis keywords are identified, the probabilistic LLM is halted immediately. The UI renders unbypassable direct hotlines (Tele-MANAS 14416, 988 Lifeline, and Vandrevala Foundation) along with verified emergency contacts.
No Sycophantic Chatbot Hallucinations: Rather than simulating a pseudo-psychiatrist chatbot that can generate erratic advice, the tool acts as a reflective mirror: presenting raw time-series trend lines and recommending structured human behavioral steps (micro-breaks, scheduling adjustments, speaking with a licensed clinician).
