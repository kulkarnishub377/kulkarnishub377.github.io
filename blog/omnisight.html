Modern industrial plants, high-security facilities, and transport hubs operate under a dangerous paradox: they have hundreds of high-definition RTSP surveillance cameras and IoT sensors installed, yet control room personnel suffer from acute alert fatigue. Operators receive upwards of 2,400 raw sensor warnings per shift—94% of which turn out to be transient false alarms, lighting flickers, or benign process variations. When a genuine crisis occurs—such as a chemical valve blowout accompanied by acoustic pressure shifts and smoke—critical minutes are squandered manually correlating fragmented dashboards.

OmniSight was architected to eliminate this cognitive bottleneck. Rather than treating computer vision and sensor telemetry as isolated alert generators, OmniSight functions as an autonomous multi-modal incident investigator. It continuously correlates spatial-temporal signals across camera topologies, verifies anomalies against Standard Operating Procedures (SOPs) stored in vector memory, and executes deterministic containment workflows within 180 milliseconds.

1. The Problem Space: Alert Storms & Blind Spots

Before detailing our software architecture, consider the physical reality of monitored environments:

  • Temporal Cascades: A single mechanical bearing failure produces a vibrational spike at t = 0s, thermal elevation at t = 12s, high-frequency acoustic squeal at t = 19s, and visible vapor/smoke at t = 45s. Traditional threshold rules treat these as 4 disconnected events, triggering 4 alerts to different engineering queues.
  • Cross-Camera Occlusion: An unauthorized personnel intrusion or forklift violation passes across 6 consecutive camera coverage zones over 90 seconds. Without cross-camera re-identification and spatial topology awareness, operators get 6 independent alarms with no coherent tracking history.
  • Unbounded LLM Hallucination Risk: Standard Generative AI agents cannot be directly wired to industrial actuators (e.g. emergency sprinkler systems or production line stop switches) without a mathematically deterministic safety guardrail.
Architectural Objective

Build an event-driven fabric that transforms raw, uncoordinated multi-modal sensor inputs into structured, audit-ready incidents in real time, grounding every autonomous recommendation in verified SOP documents with verifiable zero-hallucination guarantees.

2. System Architecture: Edge-to-Cloud Distributed Fabric

To maintain sub-200ms latency without incurring massive cloud streaming costs, OmniSight employs a hybrid edge-compute topology. Edge nodes (NVIDIA Jetson AGX Orin) handle high-fps video decoding, tensor-accelerated object detection, and acoustic FFT transforms locally. Only structured metadata vectors and triggered incident clips are streamed upstream over gRPC to the central LangGraph orchestration cluster.

3. The 6-Agent LangGraph Orchestration Engine

Unlike monolithic LLM wrappers that dump raw prompts into a single chat completion endpoint, OmniSight delegates investigation steps across six specialized autonomous agents arranged as a directed cyclical graph in LangGraph:

AGENT 01 • SENSORY OBSERVER

Observer Agent

Continuously consumes filtered edge telemetry from Kafka. Normalizes bounding boxes, temperature readouts, and acoustic anomaly scores into a standardized schema.

AGENT 02 • TEMPORAL CORRELATOR

Correlator Agent

Executes rolling 45-second sliding windows. Clusters anomalies matching physical proximity and temporal proximity, collapsing alert storms into a single Incident Entity.

AGENT 03 • SEMANTIC RETRIEVER

Knowledge Agent

Translates spatial incident metadata into hybrid dense (BGE-M3) and sparse (BM25) queries against Qdrant, retrieving exact plant SOP chapters and hazard guidelines.

AGENT 04 • REASONING INVESTIGATOR

Investigator Agent

Performs chain-of-thought hypothesis testing. Evaluates camera frame crops alongside retrieved SOP protocols to diagnose root cause and risk severity (Sev 1–4).

AGENT 05 • DETERMINISTIC GUARD

Policy Safety Guard

Strict non-LLM rule engine verifying proposed actions against safety constraints (e.g. ISO-13849). Prevents hallucinated commands or unauthorized physical actuation.

AGENT 06 • DISPATCH EXECUTOR

Action Executor

Constructs signed webhook payloads, updates Operator Dashboard over WebSockets, generates audit-ready PDF incident logs, and triggers automated PLC interlocks.

4. Multi-Modal Fusion: Real-Time Sliding Window Correlator

The bedrock of OmniSight's reliability is its temporal correlation layer. The following production FastAPI snippet demonstrates how high-frequency edge events are ingested asynchronously, matched against active incident contexts, and deduplicated using spatial-temporal decay weights:

omnisight/engine/correlator.py Python 3.11 / FastAPI / Pydantic 
import time
from typing import Dict, List, Optional
from pydantic import BaseModel, Field
import numpy as np

class AnomalyEvent(BaseModel):
    event_id: str
    source_id: str          # e.g., "CAM_04_SOUTH_BAY" or "IOT_TEMP_VALVE_12"
    modality: str           # "vision" | "acoustic" | "thermal" | "rfid"
    severity_score: float   # 0.0 to 1.0
    detected_class: str     # e.g., "smoke_plume", "overheat_critical"
    timestamp: float = Field(default_factory=time.time)
    embedding: Optional[List[float]] = None

class IncidentCluster:
    def __init__(self, incident_id: str, seed_event: AnomalyEvent):
        self.incident_id = incident_id
        self.events: List[AnomalyEvent] = [seed_event]
        self.created_at = seed_event.timestamp
        self.last_updated = seed_event.timestamp
        self.max_severity = seed_event.severity_score

    def should_merge(self, event: AnomalyEvent, max_delta_s: float = 30.0) -> bool:
        """Determines if a new sensor event belongs to this temporal incident cluster."""
        time_delta = abs(event.timestamp - self.last_updated)
        if time_delta > max_delta_s:
            return False
        
        # Cross-modality temporal boost
        is_same_location = event.source_id.split("_")[1] == self.events[0].source_id.split("_")[1]
        return is_same_location or (time_delta < 5.0 and event.severity_score > 0.85)

    def add_event(self, event: AnomalyEvent):
        self.events.append(event)
        self.last_updated = event.timestamp
        self.max_severity = max(self.max_severity, event.severity_score)

class SpatialTemporalEngine:
    def __init__(self, correlation_window_sec: float = 45.0):
        self.window_sec = correlation_window_sec
        self.active_clusters: Dict[str, IncidentCluster] = {}

    def ingest_event(self, event: AnomalyEvent) -> Optional[IncidentCluster]:
        now = time.time()
        # Clean up expired clusters
        self.active_clusters = {
            cid: cluster for cid, cluster in self.active_clusters.items()
            if (now - cluster.last_updated) <= self.window_sec
        }

        # Check existing active clusters
        for cluster in self.active_clusters.values():
            if cluster.should_merge(event, max_delta_s=self.window_sec):
                cluster.add_event(event)
                return cluster

        # Create new incident cluster if anomaly is actionable
        if event.severity_score >= 0.65:
            new_id = f"INC-{int(now * 1000)}-{event.source_id[:6]}"
            new_cluster = IncidentCluster(incident_id=new_id, seed_event=event)
            self.active_clusters[new_id] = new_cluster
            return new_cluster

        return None

5. Hybrid RAG & SOP Grounding

Industrial safety regulations mandate that autonomous systems never invent containment procedures. OmniSight solves this via a hybrid retrieval engine indexing complete plant safety manuals, chemical datasheets (MSDS), and electrical schematics into Qdrant.

When an incident cluster is formed, the Knowledge Agent synthesizes an incident summary query and executes reciprocal rank fusion (RRF) between dense semantic vectors and sparse BM25 tokens:

omnisight/retrieval/hybrid_rag.py Qdrant Client / Reciprocal Rank Fusion 
from qdrant_client import QdrantClient
from qdrant_client.http import models

def fetch_incident_sop(client: QdrantClient, query_text: str, dense_vec: list, sparse_indices: list, sparse_values: list):
    """
    Executes hybrid dense + sparse retrieval with Reciprocal Rank Fusion (RRF)
    guaranteeing deterministic citation of standard operating procedures.
    """
    results = client.query_points(
        collection_name="industrial_sops",
        prefetch=[
            models.Prefetch(
                query=dense_vec,
                using="dense",
                limit=10
            ),
            models.Prefetch(
                query=models.SparseVector(indices=sparse_indices, values=sparse_values),
                using="sparse",
                limit=10
            ),
        ],
        query=models.FusionQuery(fusion=models.Fusion.RRF),
        limit=3
    )
    
    citations = []
    for hit in results.points:
        citations.append({
            "sop_id": hit.payload["sop_id"],
            "section": hit.payload["section_title"],
            "mandatory_actions": hit.payload["actions"],
            "safety_level": hit.payload["required_ppe"],
            "score": hit.score
        })
    return citations

7. Key Engineering Challenges Solved

CHALLENGE 01

Zero-Copy Video Pipeline on Jetson Orin

Decoding 50 RTSP H.264 streams into CPU memory caused severe memory bandwidth contention. We restructured the ingest pipeline using NVIDIA DeepStream and PyCUDA to retain decoded video frames inside Unified GPU Memory, running inference directly without host-to-device memory copies.

CHALLENGE 02

Deterministic Safety Barrier (Anti-Hallucination)

LLMs can be induced to generate erroneous action parameters. The Policy Safety Guard sits between the LLM and the executor. It validates all proposed parameters against a strongly typed Pydantic schema and immutable physical rule tables, rejecting any out-of-bound requests.

CHALLENGE 03

Cross-Camera Re-Identification Without Server Overload

Tracking individuals and vehicles across disjoint camera zones required lightweight re-ID embeddings. We deployed OSNet quantized to INT8 with TensorRT, extracting 512-dimensional embeddings in 3.1ms per detection on the edge.

CHALLENGE 04

Asynchronous WebSocket Fan-Out

During major incidents, hundreds of browser clients connect to the incident stream simultaneously. We engineered a Redis Pub/Sub backplane driving FastAPI WebSockets, streaming state diffs at 60 FPS without event loop blockage.

8. Production Takeaways & Next Horizons

Building OmniSight confirmed that the true challenge in physical-world AI is not model accuracy in isolation—it is context coordination and deterministic safety. A 98% mAP vision model is useless if it drowns operators in unverified alerts or hallucinates remediation steps during a chemical spill.

By decoupling raw perception (YOLOv8 + TensorRT on Edge) from structured reasoning (LangGraph + Hybrid RAG on Cloud) and enforcing a deterministic safety firewall, OmniSight provides an industrial-grade blueprint for autonomous physical operations.
