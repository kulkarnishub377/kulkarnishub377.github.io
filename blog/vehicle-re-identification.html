Vehicle Re-Identification without a Database

Building an intelligent, image-based vehicle matching platform using YOLOv5 and OSNet-AIN with zero database dependencies.

The Vehicle Re-Identification System is a complete, standalone application for matching vehicles across images using state-of-the-art deep learning models. Unlike traditional systems, this implementation operates entirely in-memory.

<100ms Search Latency
0 Databases Used
512-dim Embeddings

1. Overview

No database is required—it uses pure in-memory, real-time processing to perform vehicle forensic matching. This makes it incredibly fast, easy to deploy, and perfectly suited for stateless, ephemeral environments like serverless functions or lightweight containers.

2. Key Features

  • Automated Vehicle Detection: YOLOv5 for accurate vehicle localization.
  • Deep Learning Embeddings: OSNet-AIN generates 512-dimensional vectors representing visual features.
  • Real-Time Vector Search: FAISS in-memory indexing for sub-100ms searches.
  • Confidence Scoring: Intelligent match classification (confident/probable/weak).

3. System Architecture

A microservice design with 5 focused services ensures clear separation of concerns. The FastAPI backend provides an async REST API with automatic documentation. The frontend is built using standard HTML5/CSS3/Vanilla JavaScript with a drag-and-drop interface for simple testing and demonstration.

4. Tech Stack

Backend: Python, FastAPI, PyTorch, YOLO, FAISS
Frontend: HTML5, CSS3, Vanilla JavaScript
Models: YOLOv5 (detection), OSNet-AIN (embeddings)
Deployment: Docker, Docker Compose
